# webvulnebilityscanner
A Python-based Web Vulnerability Scanner designed to automate security assessments using multiple open-source security tools.

## Features

- Web Application Fingerprinting
- Open Port Detection
- DNS Enumeration
- Subdomain Discovery
- SSL/TLS Security Checks
- Vulnerability Assessment
- Directory & File Enumeration
- CMS Detection (WordPress, Joomla, Drupal)

## Integrated Tools

- Nmap
- Nikto
- Wafw00f
- DNSRecon
- DNSWalk
- Wapiti
- WhatWeb
- Amass
- Dirb
- XSStrike/XSSer

## Installation

```bash
git clone https://github.com/ZeRo9cyber/webvulnerabilityscanner.git
cd webvulnerabilityscanner
python3 webvulnerabilityscanner.py target.com
```

## Usage

```bash
python3 webvulnerabilityscanner.py example.com
```
